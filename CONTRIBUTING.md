# Contributing

Thanks for your interest in contributing to this project.

This repository is used as a personal learning and practice project, but contributions, suggestions, and improvements are welcome.

## How to contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes with clear and focused commits.
4. Open a pull request with a concise description of the improvement.

## Code guidelines

- Keep examples clear and educational.
- Follow the existing TypeScript style and structure.
- Prefer readable, well-commented code.
- Avoid introducing unrelated changes.
- Keep commit messages descriptive and concise.

## Reporting issues

If you find a bug, typo, or improvement opportunity, please open an issue with:

- a clear description
- steps to reproduce (if applicable)
- expected behavior
- actual behavior
- relevant code snippets or screenshots

## Pull request checklist

Before submitting a pull request, please confirm:

- the change is relevant to the project goals
- the code or examples still compile correctly
- the README and docs remain accurate
- the change does not break the existing structure of the project

## Code of conduct

Please review [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating in the project.
