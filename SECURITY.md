# Security Policy

## Supported versions

This repository is primarily a learning and examples project. Security updates are handled on a best-effort basis.

## Reporting a vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately by contacting the repository owner via GitHub or the preferred secure contact method available in the project profile.

Please include:

- a detailed description of the vulnerability
- steps to reproduce it
- the impact of the issue
- any suggested fix or mitigation

We will review the report and respond as quickly as possible.

## Disclosure policy

We ask that vulnerabilities be reported privately first so they can be fixed before public disclosure. Once a fix is ready, we may coordinate a public advisory if needed.

## Scope

This policy applies to the project code, examples, configuration, and repository content.
