# TypeScript Basics

This repository is a personal learning project focused on TypeScript fundamentals, practical examples, and hands-on exercises inspired by Adam Freeman's book, TypeScript Basics.

The goal of this repository is to strengthen understanding of TypeScript concepts such as type safety, interfaces, classes, generics, decorators, modules, and modern JavaScript integration in real-world development workflows.

## Overview

The project contains chapter-based examples and experiments covering the core areas of TypeScript development, including:

- primitive and advanced types
- functions and type inference
- arrays, tuples, and enums
- objects, interfaces, and type aliases
- classes and inheritance
- generics and advanced patterns
- decorators and metadata
- JavaScript interoperability
- front-end and web app integration
- testing and build configuration

## Why this repository exists

This project is designed as a structured learning workspace where TypeScript concepts are practiced step by step. Each chapter focuses on one area of the language, allowing for gradual progression from basics to more advanced usage.

## Learning path

The repository follows a chapter-based progression similar to the book:

1. TypeScript setup and tooling
2. Core types and type system
3. Functions and parameters
4. Arrays, tuples, and enums
5. Objects and interfaces
6. Classes and inheritance
7. Generics
8. Advanced TypeScript patterns
9. Modules and JavaScript interoperability
10. Front-end and application examples
